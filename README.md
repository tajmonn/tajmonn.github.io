# 🪪 Portfolio Website

Personal portfolio website showcasing my projects, experience, and skills.

🌐 **Live version:** https://tajmonn.github.io

---

## ✨ About

This is my personal portfolio website built to present:
- selected projects
- technical skills
- experience and education
- contact information

The site is designed to be lightweight, fast, and minimalistic.

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **Markdown** (for content)
- **Custom web fonts (Nerd Fonts)**
- **No frameworks** – pure, simple, and fast

---
